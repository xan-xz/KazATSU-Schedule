# UniFlow Schedule

Планировщик учебного расписания на чистых HTML, CSS и JavaScript. Логика выбора расписания вдохновлена публичной страницей https://wkatu.edu.kz/sabak-kestesi/. Это независимый проект, не официальный сервис университета.

## Возможности

- Выбор института, специальности, группы и учебной недели.
- Отдельные разделы занятий, экзаменов и летнего семестра.
- Создание, изменение и удаление групп и занятий.
- Общие занятия и подгруппы A/B.
- Повторение каждую неделю, по чётным/нечётным или указанным неделям.
- Проверка пересечений времени внутри группы и подгруппы.
- Карточки по дням, таблица и печать.
- Экспорт и импорт JSON с проверкой структуры.
- Адаптивная мобильная версия и режим контрастности.

## Запуск

Установите Node.js 18 или новее. В каталоге проекта выполните:

```sh
npm start
```

Откройте http://127.0.0.1:5178. Установка зависимостей и сборка не нужны.

Нажмите «Моё расписание», добавьте группу, затем занятия. Для знакомства есть кнопка «Посмотреть пример»; демонстрационные записи не являются актуальным расписанием университета.

## Проверки

```sh
npm test
```

Проверяются структура импорта, даты, повторения, экранирование текста, демонстрационные записи и фильтр подгруппы. Это проверки логики с имитацией DOM; они не заменяют тестирование в браузере.

## Исходники

```text
public/index.html  — интерфейс и формы
public/style.css   — стили, адаптивность и печать
public/app.js      — данные, фильтры и редактор
server.mjs        — локальный статический сервер
test.cjs          — проверки логики
```

## Хранение данных

Расписание сохраняется в localStorage текущего браузера под ключом `uniflow-schedule-v1`. Серверной базы, авторизации и общей синхронизации между пользователями или устройствами нет. Экспортируйте JSON для резервного копирования и переноса. Импорт заменяет все текущие группы и занятия после подтверждения.

На одном устройстве вкладки одного адреса получают изменения через событие `storage`. При смене домена или очистке данных браузера прежнее расписание не переносится автоматически.

## Размещение

Содержимое `public/` можно разместить на любом статическом хостинге. Все пути к скриптам и стилям относительные, поэтому поддерживается размещение в подкаталоге. Локальный `server.mjs` не предназначен для публичного сервера.

В репозитории нет ключей, токенов, служебных настроек Sites или пользовательского расписания. Демо-данные создаются только после нажатия пользователем соответствующей кнопки.

## Основное расписание из Excel

В `public/schedule-data.js` встроены 25 групп из добавленного файла Excel. При первом открытии они доступны автоматически. При обновлении добавляются только отсутствующие группы; существующие локальные занятия не перезаписываются. Кнопка «Загрузить основное» позволяет явно заменить локальные данные исходными после подтверждения.

В группах показан язык обучения. 12 неоднозначных записей снабжены примечаниями. Подробности, соответствие групп и допущения по датам — в [отчёте переноса](docs/schedule-import.md). Изменения расписания на конкретном устройстве по-прежнему сохраняются в localStorage, а не отправляются в GitHub.
